# WMWave Classic - Corporate Portal

A clean, 100% corporate edition of the WMWave enterprise workforce and access control website.
Engineered for ultra-fast load times, precision layout, and zero 3D / animation overhead.

## Core Features
- **All 46 Enterprise Hardware Models**: Full catalog with detailed technical specifications, biometric storage capacities, communication interfaces, and major applications.
- **Enterprise Service Modules**: Cloud Attendance, Access Control, Security & Barrier Automation, HRMS Analytics, Visitor Management, and Canteen Automation.
- **Zero 3D & Zero Animations**: No Three.js canvas, no Framer Motion, no bounce effects. Clean solid cards, crisp typography, and high performance.
- **Corporate Pages**:
  - `Home`: Overview, enterprise sector trust grid, unified ecosystem, flagship devices, architecture, RFP banner.
  - `About`: Company profile, engineering principles, hardware reliability, security standards, facility details.
  - `Services`: Comprehensive operational breakdown of all 6 cloud workforce modules.
  - `Products`: Complete 46-product catalog with category filters, real-time search, and technical spec sheets.
  - `Blogs & Case Studies`: In-depth enterprise case studies and technical whitepapers.
  - `FAQ`: Categorized enterprise FAQs with instant-open accordion and search filter.
  - `Contact`: Office details, direct department contacts (Sales, Tech Support, Enquiries), and Google Maps embed.

## Quick Start
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

## Firebase Deployment
This project includes pre-configured `firebase.json` for Firebase Hosting:
```bash
# Login to Firebase
firebase login

# Deploy hosting
firebase deploy --only hosting
```
